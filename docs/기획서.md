# Quest Planner 기획서

> 현실의 하루를 퀘스트로, 나를 캐릭터로 (`manifest.json` 설명 기준)

- 작성 기준: 2026-09-30 시점 코드 (`index.html`, `social.js`, `server/server.js`, `render.yaml`)
- 별도의 기존 기획 문서가 없어, 이 문서는 **구현된 코드에서 역으로 정리한 현행 기획**입니다. 의도·목표는 코드에서 추정한 부분이 있으며 해당 항목에 표시했습니다.

---

## 1. 개요

| 항목 | 내용 |
|---|---|
| 제품 | 게임형 습관·할 일 관리 앱 (PWA) |
| 컨셉 | 할 일을 퀘스트로 등록·완료 → XP/골드/스탯 획득 → 캐릭터 성장 |
| 플랫폼 | 모바일 웹, 홈 화면 설치(PWA, `display: standalone`, 세로 고정) |
| 클라이언트 | 단일 `index.html`(약 6,100줄) + `social.js` + `service-worker.js` |
| 서버 | Node.js/Express + MongoDB, Render 무료 플랜 배포 |
| 데이터 | 로컬 저장이 기본. 로그인 시 퀘스트 목록·점수만 서버 저장 |

### 1.1 타깃과 문제 정의 (추정)
- 타깃: 할 일 앱을 금방 그만두는 사용자, 게임 요소에 동기부여를 받는 사용자
- 문제: 일반 할 일 앱은 완료해도 보상감이 없어 지속하기 어렵다
- 해법: 완료마다 즉각적인 보상 연출과 장기 성장(레벨·진화·수집)을 제공

## 2. 핵심 루프

```
퀘스트 등록 → 완료 체크 → XP·골드·스탯 획득 → 레벨업/진화
      ↑                                        ↓
   출석·연속일  ←  상점·장비(보상 배율 강화)  ←  골드 사용
```

### 2.1 퀘스트
- 유형: 일일 / 일반 / 요일 반복 / 마감일 지정
- 필드: 제목, 카테고리, 난이도(쉬움·보통·어려움·매우어려움), XP, 골드
- 카테고리 6종: 운동, 공부, 창작, 생활, 사회, 기타
- 완료·완료 취소·수정·삭제 가능. 취소 시 XP·골드·완료 수가 되돌아감
- 연속 완료 시 연출을 축약(2.5초 이내 재완료)
- 캘린더 연동: `.ics` 내보내기

### 2.2 보상과 스탯
| 카테고리 | 오르는 스탯 | 증가량 |
|---|---|---|
| 운동 | 체력 | +5 |
| 공부 | 지능 | +5 |
| 창작 | 창의력 | +5 |
| 생활 | 의지 | +3 |
| 사회 | 사회성 | +3 |
| 기타 | 힘 | +3 |

- 스탯 7종: 힘, 체력, 지능, 민첩, 의지, 창의력, 사회성 (초기값 각 10)
- 획득 XP·골드는 장비 보너스 배율이 적용됨

### 2.3 성장
- 레벨: 1,000 XP당 1레벨 (`levelFromXP`)
- 레벨업 연출, 진화 단계 도달 시 별도 연출
- 출석 연속일(streak), 주간 리포트(완료 수·획득 XP·완료율·연속 출석), 오늘의 경제(획득/사용 골드)

## 3. 캐릭터

직업 6종, 각각 Lv.1/5/10/20/30/50/100 진화 단계와 칭호를 가집니다.

| 직업 | 컨셉 |
|---|---|
| 전사 | 힘과 체력 (훈련병 → … → 전쟁의 신) |
| 마법사 | 지능과 마력 |
| 궁수 | 민첩과 정확도 |
| 도적 | 민첩과 은신 |
| 성기사 | 의지와 방어 |
| 연금술사 | 창의력 |

- 온보딩에서 닉네임·직업 선택 후 캐릭터 생성
- 설정: 닉네임 변경, 프로필 이미지, 보직(직업) 변경, "회귀"(초기화)

## 4. 경제·수집

### 4.1 상점 장비 (`ITEMS`)
| 슬롯 | 아이템 | 가격 | 효과 |
|---|---|---|---|
| 무기 | 낡은 목검 / 철검 / 화염검 | 80 / 300 / 900 | XP +3 / 7 / 12% |
| 방어구 | 가죽 / 사슬 / 판금 갑옷 | 80 / 300 / 900 | 골드 +3 / 7 / 12% |
| 장신구 | 행운의 부적 / 현자의 목걸이 / 모험가의 왕관 | 150 / 500 / 1,500 | XP·골드 각 +2 / 5 / 10% |

- 슬롯별 1개 장착, 캐릭터 화면에서 관리
- 상점에는 일일 코인 상자, 상점 소문(NPC 대사)이 있음

### 4.2 코인도감
- 코인 11종, 등급: 일반 / 희귀 / 영웅 / 전설
- 획득처: 퀘스트 완료 시 확률 드랍, 탐험 상자, 일일 코인 상자
- 교환소: 중복 코인을 골드·XP로 교환 (일반 15G, 희귀 40G+5XP, 영웅 120G+15XP, 전설 400G+50XP)
- 등급별·전체 완성 시 업적 보상

### 4.3 업적
- 일반 업적: 퀘스트 수, 연속 출석, 레벨(10/30/50), 코인도감 완성 등
- 시크릿 업적: 특정 시간 접속, 슬롯 잭팟, 숨은 NPC, 지하 2층, 개발자 방 등
- 업적도감 화면에서 페이지 단위로 조회

## 5. 탐험 (GPS)

| 항목 | 값 |
|---|---|
| 보물상자 | 지역(약 1km 격자)당 30개, 랜덤 배치 |
| 열기 반경 | 30m (GPS 오차 보정 최대 +40m, 정확도 100m 초과 시 불가) |
| 상자 보상 | XP 5~20, 35% 확률로 코인 |
| 걷기 목표 | 하루 1,000m |
| 부정 방지 | 속도 5m/s 초과·정확도 50m 초과 측위는 거리 미반영 |
| 기록 | 오늘 경로, 최근 14회 걷기, 활동 로그 200건 |

- 걷기 목표 초기화 주기: 매일 / 2일 / 3일
- 지도 테마(다크/컬러), 날씨 표시

## 6. 암시장

- **개장**: 월·수·금, 하루 한 번 무작위 시각·시간 (날짜 시드로 새로고침해도 동일)
- **전용 장비**: 6종(암야의 단검, 밤의 망토, 도박사의 반지, 공허의 검, 혈월 갑주, 월광 부적), 당일 4종 진열. XP·골드 보너스와 결투 승률 보너스 보유
- **티켓**: 감옥탈출(300G), 감옥 초기화(800G)
- **결투**: 상대 3종(기본 승률 48% / 40% / 33%, 배당 ×2.0 / 2.4 / 3.0), 판돈 50·100·250G. 레벨과 장비가 승률에 반영(레벨 보정 최대 +20%)
- **미니게임**: 홀짝, 슬롯머신(7️⃣ ×20 ~ 코인 ×3, 2개 일치 ×1.2), 야바위
- **안전장치(세계관 연출)**: 손실이 커지면 NPC 개입, 게임별 폐쇄 이벤트, 3게임 모두 폐쇄 시 체포 → 감옥(벌금/티켓/대기), 과도한 출입 시 단속반 이벤트
- **데일리 미니게임(홈)**: 카드 뒤집기(3단계 난이도), 금고 열기. 하루 1회 무료 보상

---

## 7. 세계관·이스터에그

- 홈 NPC 대사: 방문 횟수, 골드 0, 새벽, 전부 완료, 시장 개장일 등 상황별
- 숨은 요소: 숨은 NPC(길게 누르기), 가짜 시스템 에러, 미스터리 퀘스트(완료 시 3% 확률)
- 암시장 지하 2층: 벽 균열, 숨은 방, 검은 장부, 개발자 방
- 시간 이벤트: 새벽 2~4시, 11:11, 첫 퀘스트 1주년, 방치된 퀘스트, 과도한 연속 플레이 시 휴식 유도

## 8. 소셜 (서버)

| 기능 | API | 비고 |
|---|---|---|
| 회원가입/로그인 | `POST /api/register`, `/api/login` | JWT, 요청 횟수 제한(1시간 단위 초기화) |
| 퀘스트 동기화 | `GET·PUT /api/quests` | 최신 시각(`questsUpdatedAt`) 기준, 편집이 멎으면 한 번만 업로드 |
| 랭킹 | `PUT /api/score`, `GET /api/rank` | XP 기준 상위 50 + 내 순위 |
| 친구 | `GET /api/friends`, `POST .../request·respond·remove` | 요청/수락/삭제 |
| 채팅 | `POST·GET /api/msgs` | 폴링 방식, 낙관적 전송 |
| 푸시 알림 | `GET /api/vapid`, `POST /api/push` | Web Push(VAPID) |
| 상태 확인 | `GET /health` | Render 헬스체크 |

- 점수는 클라이언트가 보고하며 서버 검증이 없음 (서버 코드 주석: 친구끼리 쓰는 용도로 허용, 낯선 사람과 경쟁 시 서버 검증 필요)
- 퀘스트 서버 저장 시 입력값 정제(sanitize) 처리

## 11. 개선 검토 항목

코드에서 확인된 한계와 후속 과제 후보입니다. 우선순위는 미정입니다.

1. **랭킹 신뢰성**: XP를 클라이언트가 보고하므로 조작 가능. 공개 서비스로 확장하려면 서버 검증 필요
2. **동기화 범위**: 서버에는 퀘스트와 점수만 저장. 골드·장비·도감 등은 기기 로컬이라 기기 변경 시 JSON 백업에 의존
3. **채팅**: 폴링 방식. 사용량이 늘면 WebSocket 등 검토
4. **서버 콜드스타트**: Render 무료 플랜 특성상 초기 응답 지연 가능 (클라이언트에 워밍업 핑 있음)
5. **`index.html` 단일 파일 6,100줄**: 기능이 늘수록 유지보수 부담. 모듈 분리 검토
6. **미확인 사항**: 쿠폰 종류·지급 내용, 회귀의 보상 규칙은 이 문서에 포함하지 못함

## 12. 캘린더 RPG 확장안 (보완 반영)

첨부 기획서("RPG 플래너 앱 기능 기획서: 캘린더 RPG화 & 골드 소비 시스템")의 실용성 검토에서 나온 보완점을 반영한 방향입니다. 서버 동기화 관련 내용은 이번 범위에서 제외했습니다.

### 12.1 가격 균형
- 기준: 퀘스트 골드는 XP÷5(`index.html`)라서 보통 20G, 하루 5개 완료 시 약 100G입니다.
- 테마 500~5,000G는 5~50일치라 부담이 커, 아래처럼 낮춥니다.

| 항목 | 원안 | 조정안 |
|---|---|---|
| 캘린더 테마 | 500~2,000G | 300~1,500G (숲 300 / 마법학교 800 / 사이버 도시 1,500) |
| 날짜 장식 | 100~1,000G | 50~300G |
| 소모 아이템 | 100~500G | 50~200G |
| 주간 목표 보상 | 200~500G | 100~250G |

### 12.2 인플레이션 방지
- 테마 등 캘린더 아이템은 하루 구매 한도(2개)를 둡니다.
- 암시장 도박 수익과 캘린더 소비의 분리는 후속 검토 항목입니다(2차).

### 12.3 변경권·보존권 악용 방지 (2차)
- 주 2회, 같은 일정 1회로 사용 횟수를 제한합니다.
- 일정 변경 시 보상을 50%로 감액합니다.
- 보스(중요 마감) 일정에는 사용할 수 없습니다.
- 휴식권은 연속 사용을 막고, 스트릭은 유지하되 보상은 주지 않습니다.

### 12.4 범위 축소
- 1차: 월간 격자 캘린더 + 기존 `dueDate` 재사용 + 테마 3종(+기본 1종).
- 캘린더는 `calendar.js`로 분리해 `index.html`에 더 얹지 않습니다.

### 12.5 1차 구현 현황
| 항목 | 상태 |
|---|---|
| 월간 캘린더(하단 내비게이션 캘린더 탭) | 구현 |
| 마감 퀘스트·반복 퀘스트 표시, 보스(어려움 이상 마감 퀘스트) 표시 | 구현 |
| 오늘의 던전 | 12.11절의 자동 전투 던전으로 변경 (퀘스트와 분리) |
| 테마 구매/적용 (골드 소비, 일일 한도) | 구현 |
| 날짜 장식(별 50 / 불꽃 100 / 보석 200 / 룬 300G), 이펙트(반짝임 400 / 불꽃 800 / 마법진 1,200G) | 2차 구현 |
| 일정 변경권(50G)·보존권(150G) | 2차 구현 |
| 보물상자(일반·잠긴·월간) | 2차 구현 |
| NPC·스토리 기반 캘린더, 월드맵 애니메이션 | 3차 |

### 12.6 내비게이션 변경
- 하단 탭: 성장 · **캘린더** · 홈 · 탐험 · 상점 (기존 '캐릭터' 탭을 캘린더로 교체).
- 캐릭터 화면은 홈의 프로필(캐릭터 영역)을 눌러 진입합니다. 진입 중에는 홈 탭이 강조됩니다.
- 전체 퀘스트 목록은 홈의 "전체 보기"로 진입합니다. (캘린더 화면의 "전체 퀘스트" 버튼은 제거)
- 캘린더 상점의 모든 구매(테마·장식·이펙트·티켓·잠긴 상자)는 구매 확인 창(보유 골드→구매 후 골드 표시)을 거칩니다.

### 12.7 2차 구현 규칙
- **구매 한도**: 테마·날짜 장식·이펙트·잠긴 상자는 합쳐서 하루 3번까지 살 수 있습니다. 티켓은 한도 대신 사용 규칙으로 제한합니다.
- **일정 변경권(50G)**: 아직 마감 전인 마감일 퀘스트의 날짜를 오늘 이후로 바꿉니다.
- **일정 보존권(150G)**: 마감을 놓친(미완료) 퀘스트를 내일로 옮깁니다.
- **공통 제한**: 티켓 사용은 주 2회(월요일 시작), 같은 일정에는 1회, 보스(어려움 이상 마감 퀘스트)에는 사용 불가, 사용 시 그 퀘스트의 XP·골드가 50%로 줄어듭니다.
- **일반 상자**: 오늘의 던전(그날의 모든 퀘스트)을 클리어하면 하루 1개. 골드 10~30 / 경험치 15~40 / 코인(10%)이 나옵니다.
- **잠긴 상자(300G)**: 골드 100~300(50%) / 코인(30%) / 경험치 60~140(20%). 평균 가치가 구매가보다 낮게 설계했습니다.
- **월간 보물상자**: 이달 던전 클리어 10일 달성 시 미보유 테마·이펙트 중 하나(다 모았다면 300G).
- **가정한 값(조정 필요)**: 이펙트 가격, 장식 4종 가격, 잠긴 상자 확률, 월간 목표 10일은 원안에 값이 없어 제가 정한 값입니다. 실사용 골드 획득량을 본 뒤 재조정이 필요합니다.
- **미구현(후속)**: 시간 연장권, 휴식권, 퀘스트 부스터, 암시장 수익과 캘린더 소비의 분리.

### 12.9 조정 사항
- 할로윈 마을 테마를 삭제했습니다(총 6종). 이미 보유한 저장본은 기본 왕국으로 표시됩니다.
- 하루 꾸미기 구매 한도를 2회에서 3회로 늘렸습니다.
- 겨울 왕국·해적 항구·사이버 도시 테마를 컨셉별로 구분했습니다(색상, 배경 무늬, 칸 모양, 글꼴).
- 날짜 장식(테두리·아이콘·캐릭터 스탬프·특별 배경) 기능을 제거했습니다. 불꽃 이펙트는 오늘과 던전을 클리어한 날에 적용됩니다.
- HP·스트레스 게이지는 표시용이며 다른 기능에 영향을 주지 않습니다(휴식권 사용 시 0/100으로 표시, 연속 출석 보호는 휴식일 기록으로 처리).
- 기본 왕국·숲속 마을·마법 학교도 컨셉별로 구분: 기본 왕국(벽돌 무늬, 금색 아랫단 칸, 각진 모서리), 숲속 마을(이끼색 잎사귀 모양 칸, 점선 테두리), 마법 학교(별빛 배경, 아치형 칸, 마법진 점선 테두리, 보랏빛 글로우). 이제 6개 테마가 모두 서로 다른 질감입니다.

### 12.10 컨디션 시스템 (HP·스트레스)
HP와 스트레스가 표시만 하던 것에서 실제 게임에 영향을 주도록 만들었습니다.

- **스트레스** (0~100, 하루 단위): 놓친 마감 퀘스트 × 20 + 오늘 남은 퀘스트 × 5 − 진정 차 효과. 퀘스트를 완료하면 바로 내려가고, 휴식한 날은 0입니다.
- **HP** (0~100, 저장): 매일 처음 열 때 전날 스트레스로 정산합니다. 60 이상 −20 / 30 이상 −10 / 그 미만 +10 / 휴식한 날 +20.
- **컨디션 등급과 효과**: 퀘스트 완료 보상(XP·골드)에 적용됩니다.

| 등급 | 조건 | 효과 |
|---|---|---|
| 최상 | HP 90 이상 그리고 스트레스 30 미만 | 보상 +10% |
| 보통 | 그 외 | 변화 없음 |
| 피곤 | HP 50 미만 또는 스트레스 60 이상 | 보상 −10% |
| 탈진 | HP 25 미만 또는 스트레스 85 이상 | 보상 −25% |
| 휴식 | 휴식권을 쓴 날 | 변화 없음 (패널티 없음) |

- **회복 수단**: 휴식권(HP 100, 스트레스 0), 회복 포션 100G(HP +30), 진정 차 100G(오늘 스트레스 −30). 세 아이템은 보관함에서 사용합니다.
- **표시 위치**: 홈 화면 진행도 아래 한 줄(누르면 캘린더로 이동), 캘린더 위쪽 줄, 보관함의 게이지와 규칙 설명.
- **가정한 값**: 등급 기준과 보상 배율, HP 정산 수치, 아이템 가격은 제가 정한 값이며 실사용을 보고 조정해야 합니다. 완료를 취소해도 이미 받은 컨디션 보정은 되돌리지 않습니다.

### 12.11 오늘의 던전 (자동 전투) — 퀘스트와 분리
- **분리**: "오늘의 퀘스트"는 그날 퀘스트 목록(홈 화면 목록, 캘린더의 오늘 패널)이고, "오늘의 던전"은 홈 화면의 별도 카드로 새로 만든 전투 콘텐츠입니다. 던전이 퀘스트를 대체하지 않고, 퀘스트 완료가 던전의 열쇠가 됩니다.
- **열쇠**: 퀘스트를 완료하면 열쇠 1개(퀘스트당 하루 1번, 완료 취소 후 재완료해도 중복 없음, 퀘스트로 하루 최대 8개) + 매일 무료 1개.
- **구성**: 5층(1~4층 일반 몬스터, 5층 보스 "던전의 군주"). 열쇠 1개로 1층씩 자동 전투를 하고 전투 창에서 HP 바와 로그로 결과를 보여줍니다(건너뛰기 가능).
- **전투력**: 공격력 = (8 + 레벨×2 + (힘+지능)/2) × 컨디션 배율, 최대 HP = 60 + 레벨×4 + 체력×2, 치명타 = 민첩/200(최대 40%), 피해 감소 = 의지/300(최대 30%). 몬스터는 레벨에 맞춰 강해집니다.
- **진행**: 승리하면 남은 HP에 최대 HP 20%를 회복해 다음 층으로 갑니다. 패배하면 열쇠 1개를 잃고 던전 HP가 절반으로 회복되며, 컨디션 HP가 10 줄어듭니다(휴식 중에는 제외).
- **보상**: 층마다 골드 10+5×층, XP 10+5×층. 보스는 골드 60, XP 50, 일반 보물상자 1개, 30% 확률로 코인. 보스 격파가 "던전 클리어"이며 이달 클리어 일수는 월간 보물상자 조건입니다.
- **난이도(시뮬레이션 추정)**: 스탯이 초기값(10)인 1레벨 캐릭터가 열쇠 5개(퀘스트 4개 + 무료 1개)로 보스를 잡을 확률은 약 90%입니다. 스탯 성장 속도를 가정한 추정이라 실사용으로 조정이 필요합니다.

### 12.12 월드맵 (지역 성장 + 이번 달 여정)
- **탭 변경**: 하단 탭의 "탐험"을 "월드맵"으로 바꿨습니다. 월드맵 탭 위쪽의 "월드맵 / 탐험" 버튼으로 기존 GPS 탐험 화면(보물상자·걷기)을 그대로 볼 수 있습니다.
- **지역 성장**: 6개 지역(지식 던전·훈련소·제작소·마을·상업 도시·축제 지역)이 카테고리(공부·운동·창작·생활·기타·사회)와 연결됩니다. 해당 카테고리 퀘스트를 5개 완료할 때마다 지역 레벨이 오르고(최대 Lv.10), 지역 Lv.2·4·6에 새 장소가 해방됩니다. 같은 퀘스트는 하루 1번만 셉니다. 지역을 누르면 상세와 장소 목록이 나옵니다.
- **이번 달 여정**: 그 달에 던전을 클리어한 날마다 캐릭터가 길을 한 칸 나아갑니다. 10일을 클리어하면 끝의 "월간 보스" 칸에서 월간 보물상자를 받습니다.
- **던전 연결**: 월드맵 아래에 오늘의 던전 상태와 진격 버튼이 있습니다.
- **테마**: 월드맵 배경·색·글꼴은 선택한 캘린더 테마(질감 포함)를 그대로 따릅니다.
- **한계**: 지역 진행도는 이 기능 적용 이후 완료한 퀘스트부터 셉니다. 이전 기록은 반영하지 않습니다. 그림 에셋 없이 SVG로 그린 단순한 지도입니다. 지역 레벨당 5개, 해방 레벨(2·4·6)은 제가 정한 값입니다.

### 12.13 펫 시스템 (NPC 스킨 대체)
- **변경**: 캘린더 상점의 "NPC 스킨"을 없애고 펫으로 바꿨습니다. 홈 NPC의 아이콘·대사는 기본 그대로입니다. 이전에 산 NPC 스킨은 같은 펫으로 이어집니다(드래곤→드래곤, 로봇→골렘, 요정→요정).
- **동행 선택**: 산 펫 중에서 골라 최대 2마리까지 함께 다닐 수 있습니다. 교체가 아니라 펫마다 "함께하기 / 쉬게 하기"를 고르며, 자리가 가득 차면 먼저 한 마리를 쉬게 해야 합니다. 동행 중인 펫들의 효과는 모두 더해집니다.
- **성장**: 동행 중인 펫이 모두, 퀘스트를 완료할 때마다 함께 성장합니다(같은 퀘스트는 하루 1번만 셈, 10개당 1레벨, 최대 Lv.5). 쉬는 펫은 성장하지 않습니다.
- **가격순 = 강한 순서**: 비싼 펫일수록 효과의 종류가 늘고 세기도 커집니다.

| 펫 | 가격 | 효과 (레벨당 → Lv.5) |
|---|---|---|
| 말 | 1,500G | 퀘스트 골드 +2% → +10% |
| 골렘 | 2,500G | 던전 최대 HP +3% → +15%, 던전 받는 피해 −1% → −5% |
| 요정 | 3,500G | 퀘스트 XP +3% → +15%, 매일 HP 정산 회복 +2 → +10 |
| 드래곤 | 5,000G | 던전 공격력 +4% → +20%, 던전 치명타 +2%p → +10%p, 던전 골드·XP 보상 +4% → +20% |

- **표시**: 홈 화면 캐릭터 아바타 양옆에 동행 중인 펫의 아이콘과 레벨이 보이고, 누르면 이름·레벨·효과를 알려 줍니다. 상점 "펫" 탭에서 구매와 교체를 합니다.
- **가정한 값**: 말 가격, 효과 종류와 세기, 성장 속도는 제가 정한 값입니다. 이전 가격(드래곤 1,500G 등)으로 이미 산 펫은 환불하지 않고 그대로 유지됩니다. 동행 자리 수(2마리)도 제가 정한 값이며 쉽게 바꿀 수 있습니다.

### 12.14 랭킹 프로필 열람 (랭킹 전체 공개)
- **기능**: 소셜의 랭킹(과 친구 목록)에서 이름을 누르면 그 모험가의 프로필 카드가 열립니다. 랭킹에 있는 모든 사용자의 프로필을 볼 수 있고, 친구가 아니면 카드에서 바로 친구 신청을 할 수 있습니다.
- **카드 내용**: 캐릭터 모습·레벨·직업·칭호, 능력치 7종, 장비 3칸, 동행 펫과 효과, 업적 수·퀘스트 완료 수·연속 출석, 이달 던전 클리어 일수·테마·스킨, 지역 레벨 6개.
- **공개하지 않는 정보**: 골드, 퀘스트 제목·내용은 서버로 보내지도 저장하지도 않습니다.
- **공개 끄기**: 랭킹 화면 위쪽의 "내 프로필을 랭킹에 공개" 체크를 끄면 서버에서 내 프로필이 삭제되고, 다른 사람에게는 "공개하지 않았어요"로 보입니다(기본값은 공개).
- **서버 변경**: `PUT /api/score`가 프로필(허용한 필드만, 길이·범위 제한)을 함께 받고, `GET /api/profile/:nick`(로그인 필요, 분당 120회 제한)이 프로필을 돌려줍니다. 서버는 다시 배포해야 반영되며, 배포 전에는 프로필 카드가 "공유한 적이 없어요"로 보입니다.
- **한계**: 프로필 값은 앱이 알려 주는 그대로 저장되어 조작될 수 있습니다(점수와 같은 신뢰 수준). 서버 테스트는 실제 MongoDB 없이 메모리로 흉내 낸 DB에서 통과했고, 실제 DB에서는 아직 돌려 보지 못했습니다.
